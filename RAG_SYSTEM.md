# Apex Intelligence RAG Engine

## Overview

The Apex Intelligence RAG (Retrieval-Augmented Generation) Engine is a production-grade system designed to solve the critical problem of **"attribution collapse"** in AI-generated content. Every piece of analysis generated by our system is rigorously cited and traceable to its source data.

## The Problem: Attribution Collapse

As noted by technologist Ishandeep Chakraborty:

> "When AI synthesizes thousands of papers into a 'breakthrough' in hours, who actually owns that output? Science works because we can trace contributions... But when a model compresses countless inputs into something that appears novel, that chain breaks."

Our RAG system addresses this by enforcing strict citation requirements on every factual claim, ensuring a clear provenance chain from AI-generated insights back to original TCG market data.

## Architecture

```
User Query → API Gateway (Rate Limit + Auth)
          ↓
Query Embedding (OpenAI)
          ↓
Hybrid Search (Vector + Keyword + Metadata)
          ↓
Cohere Reranker
          ↓
Context Assembly with Provenance
          ↓
LLM (GPT-4o / Claude 3.5 Sonnet)
          ↓
Citation Validator
          ↓
Redis Cache
          ↓
Response with Verifiable Sources
```

## Tech Stack

- **Database**: PostgreSQL + pgvector (vector similarity search)
- **Embeddings**: OpenAI text-embedding-3-large (1536 dimensions)
- **LLM**: OpenAI GPT-4o (configurable)
- **Reranking**: Cohere rerank-english-v3.0
- **Caching**: Upstash Redis
- **Framework**: Next.js 14 + TypeScript
- **ORM**: Drizzle ORM
- **Observability**: Sentry

## Key Features

### 1. Idempotent Ingestion
- Prevents duplicate data via `unique_id` in metadata
- Automatic chunking for optimal retrieval
- Support for multiple source types (eBay, PSA, news, etc.)

### 2. Hybrid Search
- **Vector Search**: Semantic similarity via pgvector
- **Keyword Search**: BM25-style full-text search
- **Metadata Filtering**: Structured queries on card name, grade, price, etc.

### 3. Reranking
- Cohere rerank model improves retrieval quality
- Retrieves 2-3x more docs, then reranks to top N

### 4. Citation Enforcement
- Every factual claim MUST have `[source:n]` citation
- Synthesis across sources marked with `[SYNTHESIS]`
- Automatic validation rejects uncited claims

### 5. Production Ready
- Rate limiting (10 requests/minute per IP)
- Redis caching (5-minute TTL)
- Authentication hooks (ready for Stripe/Auth0)
- Comprehensive Sentry logging

## Setup

### Prerequisites

1. PostgreSQL database with pgvector extension
2. OpenAI API key
3. Cohere API key
4. Upstash Redis (optional but recommended)

### Environment Variables

Add to `.env.local`:

```bash
# Database
POSTGRES_URL="postgresql://user:password@host:5432/database"
# or
DATABASE_URL="postgresql://user:password@host:5432/database"

# OpenAI
OPENAI_API_KEY="sk-..."
OPENAI_MODEL="gpt-4o" # Optional, defaults to gpt-4o

# Cohere (for reranking)
COHERE_API_KEY="..."

# Redis (optional - enables caching)
UPSTASH_REDIS_REST_URL="https://..."
UPSTASH_REDIS_REST_TOKEN="..."

# Sentry (optional - enables error tracking)
SENTRY_DSN="..."
```

```bash

npm run db:migrate
```

### Ingest Sample Data

```bash

```

## Usage

### API Endpoint

**POST** `/api/rag`

Request:
```json
{
  "query": "What is the ROI on PSA 10 vs BGS 9.5 for 1st Edition Charizard?",
  "bypass_cache": false
}
```

Response:
```json
{
  "answer": "Based on recent market data, PSA 10 1st Edition Charizards have been selling for approximately $15,000 [source:1], while BGS 9.5 examples trade around $12,500 [source:2]. This represents a premium of approximately 20% for PSA 10 over BGS 9.5...",
  "sources": [
    {
      "id": "uuid",
      "content": "...",
      "metadata": {
        "card_name": "Charizard",
        "grade": "PSA 10",
        "sale_price": 15000,
        "auction_id": "123456789",
        "source_url": "https://ebay.com/..."
      },
      "rerankScore": 0.95
    }
  ],
  "citationCount": 5,
  "synthesisCount": 1,
  "isValid": true,
  "validationErrors": [],
  "cached": false
}
```

**GET** `/api/rag?query=...&format=markdown`

Returns markdown-formatted response with sources.

### Programmatic Usage

```typescript
import { executeRagQuery, formatRagResponse } from '@/rag/chain';

// Execute query
const response = await executeRagQuery(
  "What is the ROI on PSA 10 vs BGS 9.5 for 1st Edition Charizard?"
);

// Format for display
const markdown = formatRagResponse(response);
console.log(markdown);
```

## Citation Format

### Single Source
```
"Charizard PSA 10 sold for $15,000 on October 28, 2025 [source:1]."
```

### Multiple Sources (Synthesis)
```
"[SYNTHESIS] The market trend suggests increasing prices for graded Charizards across both PSA and BGS [source:1][source:3][source:5]."
```

### No Data Available
```
"Based on the available data, I cannot confirm the ROI for this specific variant as it is not included in the provided sources."
```

## Validation

The system automatically validates all responses to ensure:

1. Every factual claim has a citation
2. Citation numbers are within valid range
3. Synthesis markers have supporting citations
4. No speculation beyond provided data

Invalid responses trigger warnings and are logged to Sentry for review.

## Performance

- **Search latency**: ~200-500ms (hybrid search + reranking)
- **LLM latency**: ~1-3s (GPT-4o)
- **Cache hit latency**: ~50-100ms
- **Total end-to-end**: ~1.5-4s (uncached), ~50-100ms (cached)

## Scaling Considerations

- **pgvector**: IVFFlat index scales to millions of vectors
- **Redis**: Upstash Redis handles global scale with edge caching
- **Rate limiting**: Current in-memory map works for single instance; use Redis for multi-instance
- **Database**: Connection pooling configured for serverless
