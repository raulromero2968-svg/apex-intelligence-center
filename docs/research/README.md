## Core Concepts

### The Double Helix
Two strands that run parallel in every research session:
- **Strand A:** Research / Polished — Map patterns rigorously
- **Strand B:** Process / Raw — Track the researcher's emotional state

### The Luminous Jellyfish
Don't just stare into the abyss—create something beautiful in response to darkness.

### Truth Tiers
All claims are tagged by evidence quality:
1. **Adjudicated** — Court-verified
2. **Documented** — Primary source supported
3. **Circumstantial** — Corroborated but not proven
4. **Speculative** — Pattern-based hypothesis
