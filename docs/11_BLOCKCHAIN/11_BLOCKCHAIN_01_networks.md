# Blockchain Networks

## Immutable zkEVM

- **Chain ID**: 13371 (mainnet)
- **RPC URL**: Configured via `IMMUTABLE_ZKEVM_RPC_URL`
- **WebSocket URL**: Configured via `IMMUTABLE_ZKEVM_WS_URL`
- **Native Token**: ETH
- **Block Time**: ~2 seconds
- **Explorer**: https://explorer.immutable.com

### Network Details
- EVM-compatible Layer 2
- Uses zk-rollup technology
- Supports standard ERC-721 and ERC-1155 NFT contracts
- Orderbook contracts for marketplace functionality

## Ronin

- **Chain ID**: 2020 (mainnet)
- **RPC URL**: Configured via `RONIN_RPC_URL`
- **WebSocket URL**: Configured via `RONIN_WS_URL`
- **Native Token**: RON
- **Block Time**: ~3 seconds
- **Explorer**: https://app.roninchain.org

### Network Details
- EVM-compatible sidechain
- Optimized for gaming applications
- Supports ERC-721 and ERC-1155 NFTs
- Native marketplace contracts
