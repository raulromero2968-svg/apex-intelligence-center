# 05: Product & Features

## Core Value Proposition
Apex Intelligence is the **Operating System for Truth**.
While competitors build "walled gardens" of data, we build **ladders over the wall**. We provide a suite of forensic tools that enable users to trace the provenance of value and the architecture of power.

## Key Features

| Feature | Description | Status |
|---|---|---|
| **The Truth Terminal (Graph Engine)** | A force-directed graph visualizing relationships between People, Institutions, and Assets across the "Seven Mountains" of power. | ✅ v1.0 Live |
| **Ghost Node Detection** | Advanced visualization of "obfuscated" actors (shell companies, "unnamed co-conspirators") to reveal the dark matter of a network. | 🚧 In Development |
| **Investigator Notebook** | A local-first, encrypted workspace for users to log pattern-matching and suspicions without fear of surveillance. Includes "Incinerate" protocol. | ✅ v1.0 Live |
| **Provenance Scan API (formerly VARC)** | AI-powered image analysis that doesn't just grade a card, but traces its history. Detects counterfeits in cards and "deepfakes" in narratives. | ✅ Implemented |
| **Double Helix Reports** | A dual-strand content format that presents rigorous analysis side-by-side with the raw, Socratic process of discovery. | ✅ Implemented |
| **Real-Time Market Data** | Live pricing for TCGs (the "Sandbox") to train users on market dynamics (liquidity, volatility, manipulation). | ✅ Implemented |

## User Journey
1.  **Discovery:** User finds an Apex Report (e.g., "The Theology of Rentism") via search.
2.  **Verification:** User clicks the "Truth Graph" to verify the sources behind the claim.
3.  **Engagement:** User engages "Apex Mode" (Investigator Notebook) to log their own findings.
4.  **Contribution:** User submits a "Solution Node" (e.g., a verified non-profit) to the Luminous Network.
