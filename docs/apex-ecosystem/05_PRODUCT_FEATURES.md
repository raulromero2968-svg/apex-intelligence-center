### 5. Investigator Notebook ("The Parking Lot")

A secure, local-only notebook for documenting investigative observations.

#### Features

| Feature | Status | Description |
|---------|--------|-------------|
| **Local Storage Only** | LIVE | Data never leaves the browser |
| **Password Protection** | LIVE | Prevent accidental exposure |
| **Incinerate Function** | LIVE | Psychological safety - flush paranoid patterns |
| **Word/Character Count** | LIVE | Track note volume |
| **Auto-Save** | LIVE | Debounced persistence |

#### Design Philosophy

The Investigator Notebook stores paranoid pattern-matching. Once recognized, these thoughts become toxic waste. The user must be able to "flush" them to return to baseline - hence the **Incinerate** button.

## Feature Principles

### 1. Progressive Disclosure

Don't overwhelm. Show complexity only when requested.

```
Level 1: Simple answer
Level 2: Supporting data
Level 3: Source documentation
Level 4: Raw methodology
```

### 2. Offline-First Where Possible

Sensitive features (like Investigator Notebook) must work without network.

### 3. Default to Privacy

- No tracking without consent
- Sensitive data local-only
- Export before delete

### 4. Exit Visibility

Every analysis dashboard must include:
- What the data shows
- What can be done about it
- Links to action resources

1. **Propose**: Open issue with use case
2. **Evaluate**: Does it make power visible?
3. **Design**: Apply Luminous Jellyfish test
4. **Build**: Truth Tier integration required
5. **Document**: Both A (feature) and B (process)
