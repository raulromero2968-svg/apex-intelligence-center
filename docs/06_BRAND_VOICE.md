# 06: Brand & Voice

## Brand Personality
Apex Intelligence is:
1.  **The Scientist:** We rely on evidence, not vibes. We cite our sources. We build models. (*Nature*)
2.  **The Watchman:** We monitor existential risks (Rentism, Exterminism). We keep the time. (*Bulletin of Atomic Scientists*)
3.  **The Explorer:** We go into the dark (The Abyss) to bring back the map. (*National Geographic*)
4.  **The Gamer:** We understand the simulation. We know the mechanics. (*Polygon*)

## Visual Identity
* **Imagery:** High-definition "Satellite Maps" of data networks. Biologically inspired UI (The Double Helix, The Jellyfish).
* **Typography:** Monospace data fonts (for Truth) paired with bold editorial serifs (for Narrative).
* **Color Palette:**
    * **The Abyss:** Deep Slate / Void Black.
    * **The Data:** Terminal Green / Signal Amber.
    * **The Luminous:** Bioluminescent Cyan / Electric Purple.
