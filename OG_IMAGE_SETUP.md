# OG Image Generation Setup

This document explains the dynamic OG (Open Graph) image generation system implemented using `@vercel/og`.

## Overview

The system generates beautiful, branded OG images for social media sharing using the Vercel OG library. Images are generated dynamically at request time using an Edge Runtime API route.

## Features

- **Dynamic Generation**: OG images are generated on-the-fly with article title and category
- **Brand Styling**: Uses Apex Intelligence brand colors (Cyan #00D9FF, Purple #9333EA, Ink background)
- **Edge Runtime**: Fast generation using Vercel Edge Runtime
- **Opt-in System**: Articles opt-in with `og: true` in frontmatter
- **Fallback Support**: Falls back to `heroImage` if `og` is not enabled

## Files Changed

### 1. API Route: `/src/app/api/og/route.tsx`
The main OG image generation endpoint. Accepts query parameters:
- `title` - Article title (required)
- `category` - Article category (optional)
- `subtitle` - Custom subtitle (optional, defaults to "TCG Market Intelligence & Research")

**Example URL**:
```
/api/og?title=Sealed%20Product%20Performance%20Study&category=Research
```

### 2. Frontmatter Interface: `/src/lib/mdx.ts`
Added `og?: boolean` field to `ArticleFrontmatter` interface to enable per-article OG image generation.

### 3. Blog Page: `/src/app/blog/[slug]/page.tsx`
Updated `generateMetadata()` to check for `og: true` and use the OG API route instead of static hero images.

### 4. Research Page: `/src/app/research/[slug]/page.tsx`
Updated `generateMetadata()` to check for `og: true` and use the OG API route instead of static hero images.

## Usage

### For New Articles

Add `og: true` to your article frontmatter:

```yaml
---
title: "Your Article Title"
category: "Research"
publishedAt: "2024-01-15"
sourceCount: 25
tags: ["Research", "Analysis"]
heroImage: "/images/articles/your-article.jpg"
og: true  # ← Enable dynamic OG image generation
sources:
  # ...
---
```

### For Existing Articles

Simply add `og: true` to the frontmatter. The system will automatically:
1. Generate a dynamic OG image when the page is requested
2. Use the article title and category for the image
3. Include proper Open Graph metadata (1200x630 dimensions)

### Testing

To test the OG image generation:

1. **Development Server**:
   ```bash
   pnpm dev
   ```

2. **Visit the OG endpoint directly**:
   ```
   http://localhost:3000/api/og?title=Test%20Title&category=Research
   ```

3. **Check article metadata**:
   Visit any article with `og: true` and inspect the `<meta>` tags in the HTML source.

4. **Social Media Preview**:
   Use tools like:
   - [Open Graph Debugger](https://www.opengraph.xyz/)
   - [Twitter Card Validator](https://cards-dev.twitter.com/validator)
   - [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/)

## Design Specifications

### Image Dimensions
- Width: 1200px
- Height: 630px
- Format: PNG (auto-generated by @vercel/og)

### Brand Colors
- **Cyan**: `#00D9FF` - Primary accent, borders, headings
- **Purple**: `#9333EA` - Secondary accent, gradients
- **Magenta**: `#FF00FF` - Tertiary accent
- **Ink**: `#0A0E1A` - Dark background
- **Ink Light**: `#1a1f3a` - Gradient background

### Typography
- Title: 72px, bold (800), gradient cyan → purple
- Category Badge: 24px, semi-bold (600), uppercase, cyan border
- Brand: 36px, bold (700), cyan
- Subtitle: 24px, medium (500), purple

1. Creating a build script that iterates through all articles with `og: true`
2. Calling the OG API route for each article
3. Saving the responses as static files
4. Updating metadata to point to static files instead of the API route

## Customization

### Adding Custom Parameters

To add custom parameters (e.g., author, date):

1. Update `/src/app/api/og/route.tsx` to accept new query params
2. Update the image template to display the new fields
3. Update `generateMetadata()` in page files to pass new params

### Changing Design

Edit `/src/app/api/og/route.tsx` and modify the JSX template. The styling uses inline styles compatible with Satori (the rendering engine).

### Using Different Fonts

Currently uses system fonts. To add custom fonts:

1. Import font files in the route
2. Pass to `ImageResponse` via the `fonts` option
3. Reference in inline styles

See [@vercel/og documentation](https://vercel.com/docs/functions/edge-functions/og-image-generation) for details.

## Deployment

The OG API route runs on Vercel Edge Runtime, which means:
- ✅ Fast global performance (edge network)
- ✅ Automatic caching of generated images
- ✅ No server cold starts
- ✅ Scales automatically

When deployed to Vercel, OG images are automatically cached at the edge for optimal performance.

## Troubleshooting

### Image not displaying
- Verify `og: true` is in frontmatter
- Check that title doesn't contain special characters that break URLs
- Test the API endpoint directly with encoded parameters

### Build failures
- Ensure `@vercel/og` is installed: `pnpm add @vercel/og`
- Check TypeScript types are correct
- Verify edge runtime is supported in your deployment

### Styling issues
- Remember: Satori supports limited CSS (mostly Flexbox)
- Use inline styles only
- Test with different title lengths
