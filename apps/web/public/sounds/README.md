# Sound Assets for Cyberpunk UI Effects

These sound files are used for the enhanced Holo-Glitch effects:
- glitch.mp3: Short neon glitch/hum sound (<50KB, 0.5s duration)
- burst.mp3: Particle burst explosion sound (<50KB, 0.5s duration)

## Requirements:
- Low-bitrate MP3 files for optimal performance
- Short duration (0.5-1s)
- Triggered only on user interaction (hover/click)
