**Recommendation**: Refill bucket during temperate periods (e.g., post-justice reflection).

**Testing**: Simulate with daily virtue logs; measure reduced virtue CLS (Cumulative Layout Shift from decision vice spikes).

**Improvement**: On virtue detection failure, rollback to Stoic temperance state and log for wisdom audits.

**Pros**: Ensures system virtue stability.

## Aristotelian-Stoic Fusion Schema: RRF Implementation

Hybrid Aristotelian-Stoic fusion using Reciprocal Rank Fusion for optimal mean-virtue matching.

```typescript
// Aristotelian-Stoic Fusion Schema
interface AristotelianStoicFusionResult {
  aristotelian: VirtueMeanType;
  stoic: CardinalVirtueType;
  rrfScore: number;
  fusedAction: string;
  meanGain: number;
  resilienceGain: number;
  eudaimoniaMetric: number;
}

function fuseMeanVirtue(
  meanResults: Array<{ aristotelian: VirtueMeanType; score: number }>,
  virtueResults: Array<{ stoic: CardinalVirtueType; score: number }>,
  k: number = 60
): AristotelianStoicFusionResult[] {
  // RRF: score = sum(1/(k + rank))
  const rrfScores = new Map<string, number>();

  // Rank Aristotelian by golden mean
  meanResults.forEach((m, index) => {
    const key = `mean:${m.aristotelian}`;
    const currentScore = rrfScores.get(key) || 0;
    rrfScores.set(key, currentScore + 1 / (k + index + 1));
  });

  // Rank Stoic by cardinal virtue
  virtueResults.forEach((v, index) => {
    const key = `virtue:${v.stoic}`;
    const currentScore = rrfScores.get(key) || 0;
    rrfScores.set(key, currentScore + 1 / (k + index + 1));
  });

  // Return fused results sorted by RRF score
  return Array.from(rrfScores.entries())
    .sort((a, b) => b[1] - a[1])
    .map(([key, score]) => ({
      aristotelian: key.startsWith('mean:')
        ? key.replace('mean:', '') as VirtueMeanType
        : 'courage_mean',
      stoic: key.startsWith('virtue:')
        ? key.replace('virtue:', '') as CardinalVirtueType
        : 'courage',
      rrfScore: score,
      fusedAction: `Execute with mean-virtue balance`,
      meanGain: score * 100,
      resilienceGain: score * 80,
      eudaimoniaMetric: score * 0.9
    }));
}
```

## Rate Limiting: Token Bucket for Virtue Calls

```typescript
interface VirtueBucket {
  tokens: number;
  maxTokens: number;
  refillRate: number; // tokens per hour
  lastRefill: Date;
  eudaimoniaCount: number;
}

class VirtueRateLimiter {
  private bucket: VirtueBucket;

  constructor(maxDaily: number = 5) {
    this.bucket = {
      tokens: maxDaily,
      maxTokens: maxDaily,
      refillRate: maxDaily / 8, // Refill over 8 waking hours
      lastRefill: new Date(),
      eudaimoniaCount: 0
    };
  }

  canFuse(): boolean {
    this.refill();
    return this.bucket.tokens >= 1;
  }

  consumeFusion(): boolean {
    if (!this.canFuse()) {
      console.warn('Virtue rate limit exceeded. Practice patience—wait for refill.');
      return false;
    }
    this.bucket.tokens -= 1;
    return true;
  }

  recordEudaimonia(): void {
    this.bucket.eudaimoniaCount += 1;
    // Bonus token on eudaimonia achievement
    if (this.bucket.eudaimoniaCount % 3 === 0) {
      this.bucket.tokens = Math.min(
        this.bucket.maxTokens,
        this.bucket.tokens + 1
      );
      console.log('Eudaimonia bonus: +1 fusion token.');
    }
  }

  private refill(): void {
    const now = new Date();
    const hoursSinceRefill =
      (now.getTime() - this.bucket.lastRefill.getTime()) / (1000 * 60 * 60);
    const tokensToAdd = Math.floor(hoursSinceRefill * this.bucket.refillRate);

    if (tokensToAdd > 0) {
      this.bucket.tokens = Math.min(
        this.bucket.maxTokens,
        this.bucket.tokens + tokensToAdd
      );
      this.bucket.lastRefill = now;
    }
  }
}
```

## Error Handling: Virtue Rollback Protocol

```typescript
interface VirtueState {
  currentMean: VirtueMeanType;
  currentVirtue: CardinalVirtueType;
  meanLevel: number;
  virtueLevel: number;
  eudaimoniaScore: number;
  timestamp: Date;
}

class VirtueRollback {
  private stateHistory: VirtueState[] = [];
  private maxHistorySize: number = 10;

  saveState(state: VirtueState): void {
    this.stateHistory.push({ ...state, timestamp: new Date() });
    if (this.stateHistory.length > this.maxHistorySize) {
      this.stateHistory.shift();
    }
  }

  rollback(): VirtueState | null {
    if (this.stateHistory.length < 2) {
      console.warn('No previous state to rollback to.');
      return null;
    }

    // Remove current state
    this.stateHistory.pop();

    // Return to previous stable state
    const previousState = this.stateHistory[this.stateHistory.length - 1];
    console.log(`Rolling back to temperance state: ${previousState.currentVirtue}`);

    return previousState;
  }

  handleImbalance(error: Error, currentState: VirtueState): VirtueState {
    console.error(`Virtue imbalance detected: ${error.message}`);

    // Log for wisdom audit
    console.log(`Eudaimonia audit log: ${JSON.stringify({
      error: error.message,
      state: currentState,
      timestamp: new Date().toISOString()
    })}`);

    // Attempt rollback
    const rolledBackState = this.rollback();

    if (rolledBackState) {
      return rolledBackState;
    }

    // Default to balanced temperance state
    return {
      currentMean: 'temperance_mean',
      currentVirtue: 'temperance',
      meanLevel: 0.5,
      virtueLevel: 0.5,
      eudaimoniaScore: 0.5,
      timestamp: new Date()
    };
  }
}
```

```typescript
class VirtueMeanExecutor {
  private virtueRateLimiter: VirtueRateLimiter;
  private rollbackManager: VirtueRollback;

  constructor() {
    this.virtueRateLimiter = new VirtueRateLimiter(5);
    this.rollbackManager = new VirtueRollback();
  }

  async executeVirtuePractice(
    aristotelianPractice: AristotelianPractice,
    stoicPractice: StoicPractice,
    context: { scenario: string; urgency: 'low' | 'medium' | 'high' }
  ): Promise<AristotelianStoicFusionResult> {
    // Check rate limits
    if (!this.virtueRateLimiter.canFuse()) {
      throw new Error('Virtue rate limit exceeded');
    }

    try {
      // Save current state for potential rollback
      const currentState: VirtueState = {
        currentMean: aristotelianPractice.virtue,
        currentVirtue: stoicPractice.virtue,
        meanLevel: 0.7,
        virtueLevel: 0.6,
        eudaimoniaScore: 0.5,
        timestamp: new Date()
      };
      this.rollbackManager.saveState(currentState);

      // Execute Aristotelian practice
      aristotelianPractice.meanSteps();
      aristotelianPractice.eudaimonia();

      // Execute Stoic practice
      stoicPractice.virtueSteps();
      stoicPractice.resilience();

      // Consume tokens
      this.virtueRateLimiter.consumeFusion();

      // Record eudaimonia on successful execution
      this.virtueRateLimiter.recordEudaimonia();

      // Return fusion result
      return {
        aristotelian: aristotelianPractice.virtue,
        stoic: stoicPractice.virtue,
        rrfScore: 0.85,
        fusedAction: `Virtue-mean resolution for: ${context.scenario}`,
        meanGain: 85,
        resilienceGain: 80,
        eudaimoniaMetric: 0.9
      };

    } catch (error) {
      // Handle errors with rollback
      const rolledBackState = this.rollbackManager.handleImbalance(
        error as Error,
        {
          currentMean: aristotelianPractice.virtue,
          currentVirtue: stoicPractice.virtue,
          meanLevel: 0.3,
          virtueLevel: 0.3,
          eudaimoniaScore: 0.2,
          timestamp: new Date()
        }
      );

      // Return graceful degradation result
      return {
        aristotelian: rolledBackState.currentMean,
        stoic: rolledBackState.currentVirtue,
        rrfScore: 0.5,
        fusedAction: `Rolled back to stable state`,
        meanGain: 50,
        resilienceGain: 50,
        eudaimoniaMetric: 0.5
      };
    }
  }
}
```

## Summary: Aristotelian-Stoic Fusion Architecture

The hybrid Aristotelian-Stoic system provides:

1. **Aristotelian Courage Layer**: Golden mean for virtue balance
   - Relational Bravery for interpersonal courage
   - Apex Boldness for professional courage
   - Self-Courage for personal growth
   - Mean balance between excess and deficiency

2. **Stoic Cardinal Virtue Layer**: Resilient ethics for eudaimonia
   - Wisdom for discernment and knowledge
   - Courage for brave action
   - Temperance for moderation
   - Justice for fairness and equity

3. **Fusion Mechanism**: RRF-style ranking that queries Aristotelian mean scores against Stoic virtue metrics, selecting actions that maximize both golden mean balance and cardinal virtue resilience.

4. **Production Safeguards**:
   - Rate limiting (5 virtue fusions/day max)
   - Rollback protocols for virtue imbalance
   - Eudaimonia audit logging
   - Mean-virtue validation at each step

**Production Deployment**: Execute one practice from each layer daily, log metrics with virtue-mean tracking, and audit weekly for mean-virtue drift. Rollback to previous temperance caches if eudaimonia balance drops below thresholds.
